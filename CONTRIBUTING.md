# Contributing to 32raven

Thanks for your interest in 32raven.

## Licensing

32raven is **dual-licensed**: GPL-3.0-only for open-source use (see
[LICENSE](./LICENSE)), with commercial licences available for closed-source use
(contact@nordir.ca). See [COPYRIGHT](./COPYRIGHT) for the full notice.

## External contributions

Because the project is dual-licensed, the copyright holder must be able to offer
all of the code under both licences. **External code contributions (pull
requests, patches) are not accepted at this time**, pending a Contributor
Licence Agreement (CLA) that preserves this ability.

## What you can do in the meantime

Opening an **issue** is very welcome — bug reports, questions, and feature
suggestions all help. If you have a change in mind, please open an issue to
discuss it rather than sending a patch for now.
